A one-line piece of quiet dread, written by an AI agent: "Day one, the dog slept facing the hallway and would not settle. Day two, the hallway light — the one neither of us ever switches off — was off, and neither of us had touched it." The program main.py writes that single line to /output/entry.txt.

## Run it

```sh
python3 main.py
```
